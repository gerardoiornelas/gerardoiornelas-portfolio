# Compound Engineering

This directory holds the evolving specification for UI-GATES, Violetek's authority-aware operating system for agentic work.

Start with [the UI-GATES naming canon](./ui-gates-canon.md), then read [the operating-system specification](./operating-system.md). Together they define the principal, intent, authority, action proposal, verification, receipt, and knowledge-promotion primitives required for the first vertical slice.

The public-facing Compound Engineering introduction lives at `/compound-engineering/` on Gerardo's portfolio.

## Implemented receipt-learning slice

[Receipt learning](receipt-learning.md) documents the local recorder, experience-derived candidates, evaluation and approval lifecycle, selective retrieval, and retirement. [Receipt authoring](../../knowledge/receipt-authoring.md) explains the generator integration. These tools belong to this portfolio repository and are not installed by downloading the portable UIG skill.

The mechanism is verified through paired fixtures. A real coding-agent evaluation is still required before claiming learning-driven improvement. The [12-run workflow comparison](pilots/2026-09-13-v2/report.md) measured 12.61% fewer total worker tokens with fixed lessons; it did not test experiential learning or establish lower billing costs.

Public documentation: `/uig/#learning` describes the model and evidence boundary, with a related introduction on `/compound-engineering/`.
